# Birthday Gift Game Premium 💗

Премиум-версия сайта-сюрприза.

## Что нового
- ваши фотографии всплывают как полароиды;
- фото слегка наклоняются и покачиваются;
- есть романтичная надпись: «Это наши самые тёплые моменты…»;
- сердечки и анимация подарка остались.

## Как использовать
1. Распакуй архив.
2. Положи картинку сертификата в эту же папку.
3. Назови файл строго: `certificate.png`
4. Открой `index.html`

## Как отправить девушке
Лучше всего загрузить папку на Netlify Drop и отправить ссылку.

## Музыка
Если хочешь добавить музыку:
1. положи mp3 рядом с `index.html`
2. назови его `music.mp3`
3. в `index.html` у тега audio укажи: `src="music.mp3"`
